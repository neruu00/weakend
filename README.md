## 📢 소개

우리는 SSAFY에서 얻은 지식을 단순히 기억하는 데 그치지 않고, 7일간의 짧고 강렬한 호흡을 통해 백지 위에서 직접 구현하며 온전한 내 것으로 만듭니다. 최소 단위의 기능을 매주 완성하며 실전 감각과 실행력을 키우고, 그 과정에서 겪은 기술적 고민과 시행착오를 완벽하게 문서화합니다. 이러한 기록의 반복은 동료와 소통하는 협업 능력을 기르는 동시에, 자기 객관화를 통해 우리를 한 단계 더 성장시키는 강력한 자산이 될 것입니다.

> [!NOTE]
> 매주 월요일 점심 식사 이후 오프라임 모임을 진행합니다.
